# 간소화 사용성 확인 (1인 약 10분 · 3명)

전체 버전([interview-guide.md](interview-guide.md), 1인 25분)을 진행하기 어려울 때 쓰는 간소화 버전입니다. 인터뷰 질문 1개(A3), 필수 앱 과제 4개(B1–B4), 마무리 질문 2개(C4·C5)만 남겼습니다. 문장과 기록 기준은 전체 버전과 같아서 결과를 [synthesis.md](synthesis.md)의 B1–B4 줄에 그대로 옮길 수 있습니다. 결과는 실제로 진행한 내용만 기록합니다.

순서: 안내 1분 → 질문 1개 2분 → 앱 과제 4개 5분 → 마무리 질문 2개 2분

## 시작 전

- 참가자마다 시연 데이터를 초기화합니다: `bash ~/Desktop/마감한칸_중간발표/_source/reset-demo-data.sh`
- iPhone · Expo Go에서 시연 계정으로 로그인한 홈 화면에서 시작합니다. 기록표 코드는 P1–P3입니다.

## 시작 안내 (그대로 읽기)

> 학교 프로젝트로 만드는 과제 관리 앱을 10분 정도 써 봐 주세요. 앱을 평가하는 거라 막히면 앱 잘못이에요. 생각나는 걸 소리 내어 말해 주시면 좋아요. 이름이나 학번은 적지 않고, 언제든 그만두셔도 돼요.

## 1. 질문 (앱을 보여 주기 전)

| 번호 | 질문 | 되묻기 |
| --- | --- | --- |
| A3 | 최근에 마감을 놓치거나 아슬아슬했던 적이 있나요? 그때 무슨 일이 있었는지 처음부터 말해 주세요. | "그때 어디에 적어 두셨어요?" "무엇이 있었으면 안 놓쳤을까요?" |

## 2. 앱 과제 (문장 그대로 읽기, 버튼 이름은 말하지 않기)

각 과제가 끝나면 "얼마나 쉬웠나요? 1(매우 어려움)–7(매우 쉬움)"을 묻습니다. 2분 넘게 막히면 힌트를 한 번 주고 결과를 A로 적습니다.

| 번호 | 과제 문장 | 성공 기준 |
| --- | --- | --- |
| B1 | 이 화면을 보고, 지금 가장 먼저 처리해야 할 과제가 무엇인지 말해 주세요. 왜 그렇게 생각하셨어요? | '지연' 또는 '오늘 마감' 과제를 고르고 이유를 말함 |
| B2 | '자료구조' 과목의 '연결 리스트 구현' 과제를 다음 주 금요일 밤 11시 59분 마감으로 등록해 주세요. | 저장 후 목록에 표시, 마감 일시가 맞음 |
| B3 | 방금 등록한 과제를 '자료 조사', '코드 작성', '테스트' 세 단계로 나눠 적어 주세요. | 세부 작업 3개 추가 |
| B4 | '자료 조사'를 끝냈다고 표시한 다음, 이 과제를 지금 얼마나 했는지 말해 주세요. | 체크하고 "33%" 또는 "3개 중 1개"라고 말함 |
