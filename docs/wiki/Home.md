# 마감한칸 Wiki

상태: 설계 초안. 이 폴더는 Wiki에 올릴 문서 원본이며, 폴더를 커밋하는 것만으로 GitHub Wiki가 생성되지 않습니다.

GitHub Wiki에 같은 이름의 페이지를 만들고 아래 문서를 각각 복사합니다. 업로드 후에는 아래 상대 링크의 `.md`를 제거하여 `Requirements`, `Architecture`, `Test-Plan`으로 연결합니다. 저장소의 이 원본과 실제 Wiki를 함께 갱신합니다.

- [요구사항](Requirements.md): 사용자, 기능, 완료 기준.
- [구조 설계](Architecture.md): 화면, 데이터, 동작 규칙.
- [테스트 계획](Test-Plan.md): 확인할 시나리오와 기록 방법.

프로젝트 소개: 대학생이 과제를 작은 할 일로 나누고 마감과 진행률을 확인하는 개인용 모바일 앱.

회의·인터뷰·실험 문서는 실제 수행 뒤 추가합니다. 인터뷰 전 답변이나 테스트 전 통과 결과를 기록하지 않습니다.
