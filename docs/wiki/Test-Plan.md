계산과 정렬은 시간을 고정하여 자동 테스트한다. SQLite 재실행 유지와 알림 권한·예약은 실제 휴대폰에서 확인한다. 문서 변경마다 앱 테스트를 실행할 필요는 없으며 변경의 영향을 받는 부분을 확인한다.

기록 틀: 날짜 / 테스트한 커밋 / 기기·OS / 사전 데이터 / 절차 / 기대 결과 / 실제 결과 / 증빙 / 발견 Issue / 재검증 결과.

사용성 확인은 별도로 등록·세부 작업·완료·마감 확인 시나리오를 3~5명에게 관찰한다. 성공률·시간·의견은 실제 수행 후 기입한다. 최종 결과물의 범위는 기준 기기에서 핵심 시나리오 통과, 알려진 오류·제약 공개, 실행·시연 안내 완성으로 정의한다.
